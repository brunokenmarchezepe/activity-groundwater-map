Title: The Global Groundwater Monitoring Network (GGMN) dataset

Digital Object Identifier (DOI): https://doi.org/10.58154/6Z0Y-DA34

The Global Groundwater Monitoring Network (GGMN) is a collaborative initiative that collects and shares groundwater monitoring data, including groundwater levels, quality parameters, and other relevant data and metadata from national and sub-national authorities. The GGMN aims to provide reliable, comprehensive data to support groundwater research and enhance our understanding of global groundwater resources.

----------------------------------------------------

Thank you for using the GGMN platform. Please find essential information and guidelines below to ensure proper usage and citation of the data provided.

1. Data Files:

   - `monitoring` folder: Contains individual spreadsheets for each monitoring well with corresponding monitoring data.
   - `drilling_and_construction` file: Contains drilling and construction metadata for all wells. (Note: This file may be empty as the data was not found/shared.)
   - `wells` file: Provides metadata for all wells.
